SPROUTLY - CHANGES (matches the "Sproutly Journey v2" prototype)
==================================================================

Summary
-------
- New pages: landing, sign-up / log-in, onboarding, Journal.
- New "garden journal" look across the app.
- Restyled Garden and Focus. Their stores, flows and API calls are kept.
- Profile now has account settings.
- One new server route: delete account.

Not changed
- client/package.json, the pnpm lockfiles, vite.config.js, index.html, public/ and tests/.
  There are no new dependencies.
- The database schema.

The two e2e tests still use the same test ids (nav-coins, shed-tab-*, ...).

Unchanged since the prototype, on request
- The onboarding avatar was removed. Its space is kept empty (see 6).
- Preview-only parts were removed. That covers:
  - the "Preview" side tab and the stand-in browser backend
  - the single-file build config
  - the "Sky preview · dev only" bar
  - the landing page's "Interactive preview" journal demo

5. JOURNAL (new; replaces the Planner page)
-------------------------------------------
NEW   client/src/views/JournalView.vue
NEW   client/src/components/JournalBook.vue
      - An open book: to-do list on the left page, month calendar on the right.
      - Cover opening animation, page-turn between months, single-page tabs on phones,
        arrow / PgUp / PgDn keyboard control.

      - Subjects, exams and reviews due come from the garden store.

8. FOCUS
--------
CHG   client/src/views/PomodoroView.vue
      - Opens on "Set your focus & break": two big time boxes with - / + and typing.
        Classic and Deep work are quick picks.
      - Steps: Rhythm, then Topic (with one-click subjects from your garden), then Length.
      - Length is ROUNDS ONLY. The total-time option was removed.
      - Minimum focus is 1 minute. Minimum break is 0 minutes, and then focus blocks run back to back.
      - The page meadow turns to night while focusing and back to day on breaks.
      - A plant grows inside the timer ring, with one plant per block under the ring.
      - The finish screen shows a bouquet.
      - The BREAK IDEAS card was REMOVED. The BreakIdeas.vue file is kept but not used.
CHG   client/src/components/DurationInput.vue   new allowZero prop, so a break can be 0.
CHG   client/src/stores/pomodoro.js
      - errors.rhythm adds "Focus for at least 1 minute."
      - buildBlocks skips breaks when the break is 0.
      - Everything else is unchanged.
CHG   client/src/components/SessionTodo.vue and GardenRadio.vue   journal styling (vinyl, handwriting).


9. PROFILE - ACCOUNT & SETTINGS
-------------------------------
CHG   client/src/views/ProfileView.vue

          Change password: asks for the current password, the new one and a repeat.
          Log out

      - changePassword(current, next): checks the current password by signing in,
        then calls supabase.auth.updateUser.
